# Matlum Ali — Portfolio

Personal portfolio based on the original website design. The existing visual theme, layout, animations, and 3D character experience have been retained while the portfolio content and profile links were personalized.

## Run locally

1. Install **Node.js LTS** (includes npm): https://nodejs.org/
2. Extract the ZIP.
3. Open the extracted `Portfolio-Website-main` folder in VS Code.
4. Open the VS Code terminal (**Terminal → New Terminal**).
5. Install dependencies:
   ```bash
   npm install
   ```
6. Start the development server:
   ```bash
   npm run dev
   ```
7. Open the local URL printed in the terminal (usually `http://localhost:5173`).

Press `Ctrl + C` in the terminal to stop the server.

## Production build

```bash
npm run build
npm run preview
```
